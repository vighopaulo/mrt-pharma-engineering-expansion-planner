# MRT Pharma™ Digital Twin — Simplified Two-Option Model

This build compares only:

1. Conventional expansion of the existing cyclotron-centered workflow
2. MRT Pharma hybrid expansion

Major simplifications:

- Removed the new-cyclotron option
- Removed deliveries-per-point inputs
- Removed room-overlap and total-room inventory questions
- Removed workflow-uplift assumptions
- Grouped all injection and uptake room inputs together
- Replaced detailed radiopharmaceutical physics inputs with released dose capacity/day
- Added compact executive scorecards with a synchronized comparison expander
- Highlights the winning option in light green
- Uses one clean calculation module and one Streamlit interface
